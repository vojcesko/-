# Система управління завданнями з підписками

Веб-додаток для управління завданнями з системою рівнів підписки та співпраці між користувачами.

## Функціонал

### Рівні підписки

1. **Базовий рівень ($10/міс)**:
   - Ліміт: 50 тасків
   - Співпраця: Немає
   - Тільки власні таски

2. **Середній рівень ($20/міс)**:
   - Ліміт: 200 тасків
   - Співпраця: До 3 коментарів/поправок від інших користувачів
   - Можливість отримувати допомогу від інших

3. **Преміум рівень ($100/міс)**:
   - Ліміт: Безліміт тасків
   - Співпраця: Безліміт
   - Кодові фрагменти, математичні рішення
   - Повна інтеграція з іншими користувачами

### Основні можливості

- ✅ Авторизація та реєстрація користувачів
- ✅ Створення, редагування, видалення тасків
- ✅ Система підписок з обмеженнями
- ✅ Співпраця між користувачами
- ✅ Логування всіх дій
- ✅ Адмін-панель для управління
- ✅ Темна/світла тема
- ✅ Адаптивний дизайн

## Встановлення

1. Встановіть Node.js та MySQL
2. Клонуйте репозиторій
3. Встановіть залежності:
   ```bash
   npm install
   ```

4. Налаштуйте базу даних MySQL:
   ```sql
   CREATE DATABASE todo_db;
   ```

5. Оновіть налаштування підключення до БД у `server.js`:
   ```javascript
   const connection = mysql.createConnection({
     host: 'localhost',
     user: 'your_username',
     password: 'your_password',
     database: 'todo_db'
   });
   ```

6. Запустіть сервер:
   ```bash
   npm start
   ```

7. Відкрийте `index.html` у браузері

## Використання

### Для користувачів

1. Відкрийте `index.html`
2. Зареєструйтеся або увійдіть
3. Створюйте таски
4. Для співпраці натисніть кнопку "Співпраця" (доступно для середнього та преміум рівнів)
5. Переглядайте інформацію про підписку

### Для адміністраторів

1. Відкрийте `admin.html`
2. Увійдіть як адміністратор
3. Управляйте підписками користувачів
4. Переглядайте статистику та активність

## API Endpoints

### Авторизація
- `POST /api/register` - Реєстрація
- `POST /api/login` - Вхід
- `POST /api/admin/login` - Вхід адміна

### Таски
- `GET /api/todos` - Отримати таски
- `POST /api/todos` - Створити таск
- `PUT /api/todos/:id` - Оновити таск
- `DELETE /api/todos/:id` - Видалити таск

### Співпраця
- `POST /api/todos/:id/collaborate` - Додати співпрацю
- `GET /api/todos/:id/collaborations` - Отримати співпрацю

### Підписки
- `GET /api/subscription/info` - Інформація про підписку
- `GET /api/subscription/plans` - Доступні плани

### Адмін
- `GET /api/admin/users` - Список користувачів
- `PUT /api/admin/users/:id/subscription` - Оновити підписку
- `GET /api/admin/activity` - Статистика активності
